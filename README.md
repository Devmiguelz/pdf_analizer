# 🧾 Analizador de PDF

Este proyecto proporciona herramientas para analizar documentos PDF utilizando **Python**.

---

## 📦 Requisitos previos

- Python 3.8 o superior instalado en tu sistema  
- `pip` (gestor de paquetes de Python)

---

## 🚀 Instalación y configuración

### 🪟 Windows

1. **Clonar o descargar el proyecto**

   ```bash
   git clone <url-del-repositorio>
   cd <nombre-del-proyecto>
   ```

2. **Crear el ambiente virtual**

   ```bash
   python -m venv venv
   ```

3. **Activar el ambiente virtual**

   ```bash
   venv\Scripts\activate
   ```

4. **Instalar las dependencias**

   ```bash
   pip install -r requirements.txt
   ```

5. **Ejecutar el analizador de PDF**

   ```bash
   python analizar_pdf.py
   ```

---

### 🐧 Linux / macOS

1. **Clonar o descargar el proyecto**

   ```bash
   git clone <url-del-repositorio>
   cd <nombre-del-proyecto>
   ```

2. **Crear el ambiente virtual**

   ```bash
   python3 -m venv venv
   ```

3. **Activar el ambiente virtual**

   ```bash
   source venv/bin/activate
   ```

4. **Instalar las dependencias**

   ```bash
   pip install -r requirements.txt
   ```

5. **Ejecutar el analizador de PDF**

   ```bash
   python analizar_pdf.py
   ```

---

## 🔧 Desactivar el ambiente virtual

Cuando termines de trabajar, puedes desactivar el ambiente virtual con:

```bash
deactivate
```
